# i-Maahad V1.17 — Leaflet WebGIS

Prototaip sistem informasi dan pemetaan institusi pondok dan maahad negeri Kedah. Bukan portal rasmi.

## Kandungan
- `index.html`: WebGIS Leaflet menggunakan peta asas Esri.
- `data/`: 138 titik institusi dan sempadan GIS.
- `legacy/dashboard-v1.16.html`: dashboard asal sebagai rujukan.

## Cara menjalankan
Gunakan pelayan web atau GitHub Pages (fail GeoJSON dimuat melalui `fetch`; membuka `index.html` terus sebagai `file://` tidak berfungsi). Leaflet dimuat melalui CDN dan Esri memerlukan internet.

**Privasi:** Semak data sebelum menerbitkan repositori secara awam. **Lesen:** Semak syarat Esri, atribusi, dan sumber geodata sebelum penggunaan rasmi.
